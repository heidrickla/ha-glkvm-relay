# GLKVM Relay

GL.iNet's self-hosted GLKVM Cloud relay (`rttys`) and a TURN server (coturn) on the Home Assistant host: one web console for the GL.iNet KVMs on your network, with no separate server. Credentials are generated on the first start, TURN relays only to public addresses and the KVMs you list, and the TURN credential is replaced by raising one option. See `DOCS.md`.
